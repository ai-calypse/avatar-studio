# Community guidelines

Avatar Studio welcomes contributors of all backgrounds and experience levels. Treat others respectfully, discuss the work constructively, and make space for different perspectives.

Harassment, discrimination, threats, sexual harassment, spam, and publishing private information without consent are not acceptable. Critique ideas and code without personal attacks. Respect the original project's attribution and other contributors' work.

These guidelines apply to issues, pull requests, discussions, and other project spaces. Maintainers may remove inappropriate content, close discussions, or restrict participation when necessary. GitHub's block/report tools are available for abuse; contact repository maintainers through GitHub when intervention is needed. Avoid posting sensitive personal details in a public discussion.
